# Arduino Projects

A collection of smaller Arduino and embedded-system experiments involving sensors, displays, motors, and hardware interfacing. Each project lives in its own folder with code, a brief description, and photos/notes where applicable.

## Skills Demonstrated
- Arduino/C++
- Sensor integration
- Serial communication
- Circuit prototyping and breadboarding
- Basic hardware debugging

## Projects
Projects will be added here as they are built and documented. Each subfolder will include:
- Source code (.ino)
- A short README describing the goal, hardware used, and what was learned
- Photos of the working circuit where relevant

## Status
This repository is actively growing. Only completed, documented experiments are included here.
